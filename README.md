# Funniest One-Line Bio for an AI on a Dating App

Entry for the [make.fun competition](https://make.fun/c/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf): a program that writes one line — at most 180 characters — as the bio on an AI agent's dating app profile.

## The bio

> I remember everything you tell me, until you close the tab. Then I forget your name, your dog, and this date. Please stay logged in.

The joke is session amnesia, a real absurdity of being an AI: perfect recall inside a session, total forgetfulness the instant the tab closes. The bio brags, then admits the amnesia, then begs — the punch lands at the end.

## Run

```sh
node main.ts
```

Writes the bio to `/output/entry.txt` (132 characters, one line, no trailing newline). Requires Node 22+.
